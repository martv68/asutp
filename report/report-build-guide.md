# Сборка отчёта БДЗ (Typst)

Шаблон `@preview/modern-g7-32` (ГОСТ 7.32), как в НИР и ЛР. Структура
многофайловая, по образцу НИР.

## Состав
- `report.typ` — точка сборки; переменная `stage` выбирает вариант отчёта.
- `title-bdz.typ` — титульный лист (команда, этап).
- `0_2_intro.typ` — введение.
- `1_protocol.typ` — раздел 1, описание OPC UA (этап 1).
- `2_stand.typ`, `3_suricata_module.typ`, `4_rules.typ`, `5_conclusion.typ` — итоговый отчёт (этап 5).
- `assets/` — рисунки (см. `assets/README.txt`).

## Варианты отчёта
- `#let stage = 1` — введение + раздел 1, сдача до 8 недели;
- `#let stage = 5` — все разделы + заключение, сдача до 16 недели.

## Сборка
Из папки `report/`:

```sh
typst compile report.typ report.pdf
typst watch report.typ report.pdf
```

## Имя PDF при сдаче
`БДЗ ИБАСУТП 26 Группа 8.pdf`, хэштег `#АСУТП_БДЗ1_26`.

## Перед сдачей этапа 1
- собрать PDF с настоящим шаблоном и проверить титул и нумерацию таблиц.
